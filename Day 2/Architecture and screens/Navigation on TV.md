# Navigation on TV

A TV remote gives you Up, Down, Left, Right, OK, Back, and little else. There is no touchscreen.

## Remote types

| Remote | Input | Notes |
| ------ | ----- | ----- |
| Apple TV Siri Remote | D-pad plus touch surface | Swipes on the surface move focus, not content |
| Tizen and Android TV remotes | D-pad only | No touch at all |
| LG Magic Remote, some Samsung remotes | D-pad plus pointer | Acts like a mouse |

**Rule:** Every action must be reachable with the D-pad alone. Users may use the pointer or the D-pad, so you cannot rely on either one.

## The two navigation patterns that work

| Pattern | Layout | Move from content to navigation | Move from navigation back to content |
| ------- | ------ | ------------------------------- | ------------------------------------ |
| Sidebar | A vertical list of destinations | Press Left | Press Right |
| Top tabs | A horizontal row of destinations | Press Up | Press Down |

Pick one pattern per app and use it consistently. Switching between them confuses users.
